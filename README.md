# Beta-assembly-language-program
Wrote a Beta assembly language program for the count_bull_cows subroutine to calculate the number of bulls and cows in a hexadecimal Moo/Mastermind game

This program is written in Beta assembly language, designed to run on a Beta architecture CPU.

The Bsim.jar simulator is used to emulate the Beta architecture and execute lab5.uasm, which contains the assembly program. The Beta architecture definition is loaded from beta.uasm, while the checkoff file verifies the functional correctness of the assembly program

Implemented the count_bull_cows subroutine in Beta Assembly based on the reference C implementation. The function accepts two 16-bit integers, A and B (each consisting of 4 hexadecimal digits), and returns the packed result formatted as (bulls << 4) + cows.

_**Implemented in accordance with the requirements and instructions in Lab5.pdf, complete project documentation is provided in Lab5.docx**_
